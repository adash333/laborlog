# トップの紹介文と使い方ガイド

日付:2026-09-01

## プロンプト本文

> 最初のページがこちらになるので、サイトの紹介をひとこと書いてもらえますか? また、詳しい使い方はこちら みたいなページを用意して、リンクを貼ってもよいと思います

(初回アクセス時に「勤務条件の登録」画面がいきなり表示されるスクリーンショット付き)

## 結果の内容

### 初回画面のサイト紹介

`src/pages/Setup.tsx` の冒頭に、ブランドカラーの紹介カードを追加した(初回のみ表示。設定画面からの「勤務条件の変更」では非表示):

- アプリ名「まもログ」+キャッチコピー「働いた記録が、あなたを守る。」
- ひとこと紹介:毎日2タップで勤務を記録し働き方のリスクを見える化・記録は端末内のみ・無料・登録不要
- 「詳しい使い方はこちら →」ボタン(→ /guide)

あわせて見出しを「まずは勤務条件を登録」に変更し、「だいたいで大丈夫、後から変更できます」と心理的ハードルを下げた。編集モードでは見出し「勤務条件の変更」・ボタン「保存する」に切り替わる。

### 使い方ガイドページ(/guide)

`src/pages/Guide.tsx` を新設。内容:

1. まもログとは?(ローカル保存・外部送信なしの明記)
2. 最初にすること(勤務条件登録・ホーム画面に追加)
3. 毎日すること(2タップ。何もなければ追加入力不要)
4. 困ったことがあった日は(チェック・出来事の詳細記録・自由メモ)
5. リスクスコアの見方(参考指標であること・レッドフラッグ・「なぜこの点数?」)
6. 月次レポートと相談用PDF
7. データのバックアップ(重要事項として強調)
8. よくある質問(会社に見られる?/無料?/スコアが高いときは?)+免責

### 導線

- 初回セットアップ画面の紹介カードからリンク(プロフィール未登録でも /guide を閲覧可能にルーティング調整)
- 設定画面の先頭に「使い方ガイド →」を追加
- ガイド末尾の戻るボタンは、未登録なら「登録画面に戻る」・登録済みなら「ホームに戻る」に自動切替

### 検証

- ビルド・テスト成功。Playwright で「紹介カード表示→ガイド閲覧→登録画面に戻る→保存→設定からガイド→ホームに戻る」「編集モードでは紹介カード非表示」を確認・JSエラーなし
