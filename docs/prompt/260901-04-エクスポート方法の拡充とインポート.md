# エクスポート方法の拡充とインポート

日付:2026-09-01

## プロンプト本文

> データをエクスポートする方法として、メールにファイルを添付する方法、Googleドライブに保存する選択肢も用意して下さい。データをインポートする方法も用意して下さい

## 結果の内容

設定画面(`src/pages/Settings.tsx`)のバックアップ機能を「エクスポート」「インポート」の2セクションに再構成した。

### エクスポート(3つの方法)

1. **ファイルをダウンロード** — 従来どおり JSON を端末に保存
2. **メール・Googleドライブ等に送る** — Web Share API でOSの共有画面にバックアップファイルを渡す。スマートフォンでは共有先として Gmail(メール添付)・Googleドライブ(保存)・LINE 等をそのまま選べる
3. **非対応ブラウザ向けフォールバック** — 共有APIが使えない環境(主にPCブラウザ)では、自動でファイルをダウンロードした上で「メールに添付/ドライブにアップロード」の手順案内と「Gmailを開く」「Googleドライブを開く」リンクを表示

方針:ローカルファースト(サーバーなし)を維持するため、Google Drive API 連携(OAuth)は行わず、OSの共有機能とブラウザ経由のアップロードで実現した。共有シートのキャンセル(AbortError)はエラー扱いしない。

### インポート

- 「バックアップファイルを選んで復元」ボタンでファイル選択 → 確認ダイアログ → 全データ置換で復元
- メール添付・Googleドライブ上のファイルは一度端末にダウンロードしてから選択する旨を案内
- 受け付ける形式を `.json / application/json / text/plain` に広げ、メールアプリ経由でMIMEが変わったファイルにも対応
- 復元で現在データがすべて置き換わることを注意書きで明示

### 検証(Playwright・全フロー成功)

1. エクスポートしたファイルが正しいバックアップJSONであること(app: mamolog、勤務記録を含む)
2. 共有非対応環境でフォールバック案内とGmail/ドライブのリンクが表示されること
3. 全データ削除 → セットアップ画面に戻る → バックアップファイルからインポート → 「復元しました」表示 → ホームで出勤記録が復元されていること

ビルド・型チェック・ユニットテスト37件も成功。
