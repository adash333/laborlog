## 結果の内容

### mainブランチへの移行

ユーザーの明示的な許可に基づき、開発ブランチを `main` に切り替えた。以後の開発・pushはすべて `main` に対して行う。

### 実装内容(Sprint 0〜3 相当)

Vite + React + TypeScript + Tailwind CSS + Dexie.js(IndexedDB)+ PWA 構成で「まもログ」v0.1.0 を実装した。データはすべて端末内の IndexedDB に保存され、外部送信しない(ローカルファースト方針)。

#### 基盤(Sprint 0)

- `package.json` / `tsconfig.json` / `vite.config.ts`(PWA manifest 含む)/ `index.html` / `public/icon.svg`(盾+チェックのアイコン)
- `src/db.ts` — Dexie スキーマ(profile / workdays / auditLog)、JSONバックアップのエクスポート・インポート・全削除

#### 勤務記録(Sprint 1)

- `src/pages/Setup.tsx` — 勤務条件登録(雇用形態・所定時間・休憩・勤務制度・業種特例・固定残業代)
- `src/pages/Home.tsx` — 出勤・退勤の2タップ記録、退勤後の休憩5択+「今日困ったこと」チェック(実装仕様書 §5)
- `src/pages/DayEdit.tsx` — 日別修正(始業前後・自宅作業・休日勤務・出来事メモ)。修正は auditLog に履歴保存

#### 月次集計(Sprint 2)

- `src/lib/time.ts` — 在社時間・実勤務時間・必要休憩(労基法34条)・推定時間外・深夜判定(§6–7)
- `src/lib/aggregate.ts` — 月次集計(勤務日数・推定時間外・最長勤務・最大連勤・休憩不足/未入力・深夜・困ったこと件数)、データ信頼度(§38)
- `src/pages/Calendar.tsx` / `src/pages/Report.tsx` — カレンダー、月次レポート、CSVダウンロード

#### スコアリング(Sprint 3)

- `src/scoring/rules.json` — 閾値・警告文・出典URL(厚労省)を外部化(§43–46)
- `src/scoring/scoring.ts` — A長時間労働(0–30点:時間外基本点+連勤・長い1日・深夜補正)、D休憩・休日(0–15点)、レッドフラッグ(月80h/100h、14連勤)、総合レベル+レッドフラッグ優先ロジック(§30)
- `src/pages/Risk.tsx` — スコア詳細・「なぜこの点数?」・一次資料リンク・免責表示
- B未払い(25点)・Cハラスメント(20点)・E雇用圧力(10点)は未実装であることをUIに明示

#### その他

- `src/pages/Consult.tsx` — 相談先案内(公的/民間の区分、§31–33)
- `src/pages/Evidence.tsx` — 「証拠を守る」読み物7本(統一形式:何を→どう→何に役立つ→注意点)
- `src/pages/Settings.tsx` — バックアップ・復元・全削除・免責・会社端末利用の注意

### 検証

- ユニットテスト37件すべて成功(`npm test`:時間計算・月次集計・スコアリング)
- `npm run build` 成功(型チェック+本番ビルド+PWA生成)
- Playwright によるブラウザ実機テスト:初期設定→出勤→退勤→休憩・困ったこと入力→リスク画面→カレンダー→月次レポート→設定→リロード後のデータ永続化、まで全フロー動作・JSエラーなしを確認
