# カスタムドメイン化の手順案内

日付:2026-09-01

## プロンプト本文

> これを、l.5micro.net にしたいです。　5micro.netは、さくらインターネットで契約しています　やり方を教えて下さい

## 結果の内容

このターンではコード変更は行わず、`l.5micro.net` で公開するための手順を案内した(DNS設定が先でないと切り替え時にサイトが一時アクセス不能になるため、ユーザーのDNS作業待ち)。

### 案内した手順

1. **さくらインターネット側(ユーザー作業)**
   - 会員メニュー → 契約中のドメイン `5micro.net` のゾーン編集で CNAME レコードを追加
   - エントリ名 `l` / 種別 CNAME / 値 `adash333.github.io.`
   - 反映は数分〜1時間程度。既存サイトへの影響なし

2. **GitHub側(DNS反映後にこちらで実施予定)**
   - デプロイ設定(peaceiris/actions-gh-pages)に `cname: l.5micro.net` を追加して push → gh-pages に CNAME ファイルが置かれ、カスタムドメインが有効化
   - GitHub が HTTPS 証明書を自動発行(数分〜1時間)
   - 発行後、Settings → Pages で「Enforce HTTPS」にチェック(ユーザーの1クリック)
   - 旧URL `adash333.github.io/laborlog/` は新ドメインへ自動リダイレクト

### 重要な注意(ユーザーに案内済み)

- まもログのデータはドメイン単位でブラウザ内に保存されるため、**旧URLの記録データは新ドメインへ自動では移らない**
- 切り替え前に旧URLでJSONバックアップをダウンロード → 切り替え後に `l.5micro.net` で復元、という移行手順を案内
- PWAをホーム画面に追加している場合は新ドメインで再追加を推奨

### 次のアクション
