# r.5micro.net へのカスタムドメイン切替

日付:2026-09-01

## プロンプト本文

> lは使われていました。英語1文字だったら何がよいでしょうか?

> DNSチェックは?

> (ゾーン編集画面のスクリーンショット)これでよいですか?

## 結果の内容

### サブドメインの選定

`5micro.net` の1文字サブドメインをDNSで実査したところ、`m`(mamolog)・`w`(work)・`k`(勤務)・`h`・`s`・`e`・`l` は使用中、`r`・`t`・`j`・`n`・`g`・`x` が未使用だった。「record / log(記録)」の頭文字で、まもログのコンセプト「働いた記録が、あなたを守る」に合う **`r`(r.5micro.net)** を推奨し、採用された。

### DNS設定の確認と監視

- ユーザーがさくらインターネットのゾーン編集で `r` / CNAME / `adash333.github.io.` を追加(スクリーンショットで設定内容の正しさを確認)
- Google Public DNS 経由でさくらの権威サーバーを1分間隔で自動監視し、反映を検知

### GitHub側の切り替え

- `.github/workflows/deploy.yml` の peaceiris/actions-gh-pages に `cname: r.5micro.net` を追加
- これにより gh-pages ブランチに CNAME ファイルが配置され、GitHub Pages のカスタムドメインが `r.5micro.net` になる
- 旧URL `adash333.github.io/laborlog/` は新ドメインへ自動リダイレクトされる

### ユーザーに案内済みの残作業

1. HTTPS証明書の自動発行(数分〜1時間)後、リポジトリ Settings → Pages で「Enforce HTTPS」にチェック
2. 旧URLで記録したデータがある場合は、旧URLでJSONバックアップ → 新URLで復元(ドメインが変わるとブラウザ内データは引き継がれないため)
